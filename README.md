# project_a: 날씨 기반 옷 추천 서비스

## 서비스 개요

기존의 무신사 같은 패션 추천 서비스는 브랜드, 상품, 코디샷 중심으로 옷을 추천한다. 하지만 실제로 옷을 입을 때는 날씨에 따라 색감, 소재, 두께, 착용감이 어울리지 않거나 불편할 수 있다.

이 서비스는 사용자의 현재 날씨 정보를 바탕으로 그날 어울리는 옷의 색감, 소재, 두께, 분위기를 추천한다. 특정 상품을 구매하도록 유도하기보다는, 날씨에 맞는 스타일 방향과 느낌을 제안하는 것을 목표로 한다.

## 문제 정의

- 날씨가 덥거나 습하면 예쁜 옷도 불편하게 느껴질 수 있다.
- 비, 바람, 추위, 미세먼지 같은 조건에 따라 적합한 소재와 착장이 달라진다.
- 기존 패션 추천은 상품 판매나 브랜드 노출에 집중하는 경우가 많다.
- 사용자는 "무엇을 사야 하는지"보다 "오늘 어떤 느낌으로 입으면 좋은지"가 궁금할 수 있다.

## 핵심 목표

- 날씨에 맞는 옷차림 방향을 쉽고 빠르게 추천한다.
- 색감, 소재, 두께, 분위기 중심으로 추천한다.
- 쇼핑 유도보다 사용자의 하루 착장 선택을 돕는 데 집중한다.
- 사용자가 가진 옷으로도 참고할 수 있는 추천 문장을 제공한다.

## 주요 사용자

- 매일 아침 날씨에 맞춰 옷을 고르는 사람
- 패션에는 관심이 있지만 날씨에 맞는 소재나 색 조합이 어려운 사람
- 상품 구매보다 코디 방향, 분위기, 스타일 힌트를 얻고 싶은 사람
- 출근, 등교, 데이트, 운동 등 상황별 옷차림을 고민하는 사람

## 핵심 기능

### 1. 날씨 정보 입력 또는 조회

사용자는 지역을 입력하거나 현재 위치 기반으로 날씨 정보를 가져온다.

사용할 날씨 요소:

- 기온
- 체감온도
- 습도
- 강수 여부
- 풍속
- 미세먼지 또는 대기 상태
- 계절

### 2. 날씨 기반 스타일 추천

날씨 조건에 따라 적합한 옷차림 방향을 추천한다.

추천 항목:

- 상의 종류
- 하의 종류
- 아우터 필요 여부
- 추천 소재
- 피하면 좋은 소재
- 추천 색감
- 전체적인 분위기
- 간단한 코디 예시

### 3. 상황별 추천

사용자가 오늘의 목적을 선택하면 추천 결과를 더 구체화한다.

상황 예시:

- 출근
- 등교
- 데이트
- 가벼운 외출
- 운동
- 격식 있는 자리

### 4. 선호 스타일 반영

사용자의 취향을 선택하게 해서 추천 결과의 톤을 조정한다.

스타일 예시:

- 캐주얼
- 미니멀
- 스트릿
- 댄디
- 러블리
- 스포티
- 포멀

## 추천 결과 예시

### 더운 날

오늘은 기온이 높고 습도가 높아 답답하게 느껴질 수 있다. 밝은 톤의 반팔 셔츠나 얇은 티셔츠를 추천하고, 린넨이나 기능성 면처럼 통기성이 좋은 소재가 잘 어울린다. 색감은 화이트, 라이트 블루, 연한 그레이처럼 시원해 보이는 방향이 좋다.

### 비 오는 날

오늘은 비가 올 가능성이 있으므로 물에 젖었을 때 무겁거나 잘 마르지 않는 소재는 피하는 것이 좋다. 어두운 톤의 팬츠와 방수성이 있는 가벼운 아우터를 추천한다. 전체적인 분위기는 차분하고 실용적인 느낌이 어울린다.

### 추운 날

오늘은 체감온도가 낮아 보온성이 중요하다. 니트, 기모 맨투맨, 울 코트, 패딩 같은 따뜻한 소재를 추천한다. 색감은 차콜, 네이비, 브라운, 딥그린처럼 안정감 있는 톤이 잘 어울린다.

## 추천 로직 구상

처음에는 복잡한 인공지능 모델보다 규칙 기반 추천으로 시작한다.

예시 규칙:

- 기온이 28도 이상이면 얇고 통기성 좋은 소재를 추천한다.
- 습도가 높으면 린넨, 기능성 소재, 여유 있는 핏을 추천한다.
- 비가 오면 방수 아우터, 어두운 색 하의, 빠르게 마르는 소재를 추천한다.
- 체감온도가 낮으면 아우터와 보온성 있는 소재를 추천한다.
- 미세먼지가 나쁘면 세탁이 쉬운 외투와 마스크 착용을 고려한 스타일을 추천한다.

이후 데이터가 쌓이면 사용자 피드백을 반영해서 추천 정확도를 개선할 수 있다.

## MVP 개발 범위

1차 버전에서는 다음 기능만 구현한다.

- 지역 또는 날씨 조건 입력
- 기온, 습도, 비 여부 기반 추천
- 추천 색감, 소재, 옷 종류 출력
- 상황 선택 기능
- 간단한 웹 화면

1차 버전에서 제외할 기능:

- 실제 상품 구매 연결
- 로그인
- 사용자 옷장 관리
- 이미지 기반 코디 분석
- 복잡한 AI 추천 모델

- 현재 날씨 표시
- 오늘의 상황 선택
- 선호 스타일 선택

- 전체 스타일 한 줄 요약

## 기술 계획

초기 구현은 간단한 웹 서비스 형태로 만든다.

예상 기술:

- Frontend: HTML, CSS, JavaScript 또는 React
- Weather API: OpenWeatherMap API, 기상청 API 등

## 최종 목표

이 서비스의 최종 목표는 사용자가 매일 아침 옷을 고를 때 날씨와 분위기를 함께 고려할 수 있도록 돕는 것이다. 단순히 상품을 보여주는 패션 서비스가 아니라, 오늘의 날씨에 어울리는 착장 감각을 제안하는 개인 스타일 가이드가 되는 것을 목표로 한다.
